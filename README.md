# SmartPark – Smart Parking Fee Calculator

## Project Objective
SmartPark manages vehicle parking records and calculates parking fees based on parking duration.

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Java
- Data Structure: Array
- Concepts: Searching, Insertion, Deletion, Traversal, and Updating

## Features
1. Park a vehicle.
2. Remove a vehicle.
3. Calculate parking fees.
4. Display occupied parking slots.
5. Show available parking slots.

## Parking Rules
- Total parking slots: 10
- Parking fee: ₹30 per started hour
- Minimum fee: ₹30

## How to Run
1. Install JDK 17 or later.
2. Open the project folder in VS Code.
3. Compile the Java files.
4. Run the SmartPark program.
5. Open http://localhost:8080 in your browser.

## Note
Vehicle records are stored in memory. They will be cleared when the Java server stops.

## Conclusion
SmartPark uses Java arrays to manage parking slots and calculate parking fees. It provides a simple website for managing vehicle parking.
